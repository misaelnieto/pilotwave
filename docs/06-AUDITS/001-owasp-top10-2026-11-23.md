# Audit 001 — OWASP Top 10 (2021), 2026-11-23

Scope: `python/pilotwave/client.py`, `rust-worker/src/*`,
`contracts/CONTRACT.md`. Threat model: planted queue row (worker
re-validates everything; DB ACLs are the auth boundary).

## Verdicts

### A01 Broken Access Control — Mitigated, residual

Claim/reaper/status filter by queue/backend/allowlist with binds
(`rust-worker/src/db/postgres.rs`). `worker_id` validated
`[A-Za-z0-9_-]{1,64}` (`config.rs`). Residual: least-privilege
`GRANTs` are doc-only (`.env.example`); `inspect` reads any row by
UUID by design (PII exposure with CLI access).

### A02 Cryptographic Failures — Partial

`db/mod.rs::connect` has no TLS (local-only comment). `mailer.rs`
allows `builder_dangerous` when `EMAIL_USE_TLS=false`. Good:
`Env` avoids exporting whole `.env` to environ (`config.rs`),
`Debug` redacts `database_url`/`smtp_password`.

### A03 Injection — Strong

All SQL static + binds, pinned by
`sql_usa_literales_del_contrato`. Header validation
(`contract.rs::is_valid_to/is_valid_subject`) + `lettre`
re-validation close CRLF injection. `sanitize_detail` redacts
secrets + truncates to 4096 on UTF-8 boundary. No shell in
`spawn_detached` (fixed argv).

### A04 Insecure Design — Accepted risk

At-least-once without dedupe (P-4, recorded decision): duplicates
possible, producers must be idempotent by `reference`. Flood guard
`queue_full() >500` (`client.py`) is bypassable
(`depth_guard=False`) and TOCTOU. Backoff ladder + `max_attempts=5`
correct.

### A05 Misconfiguration — Dev-to-prod risk

`compose.yaml` (`pilotwave/pilotwave`), `devsettings.py`
(`SECRET_KEY` fallback, `DEBUG=True`). `.env.example` ships
`CHANGEME`. Good: attachment roots fail-closed, relative
pid/log paths fail loud.

### A06 Vulnerable Components — No scan

Pinned (`django-tasks-db==0.13.0`, `Cargo.lock`, `uv.lock`) but
`justfile` has no `audit` recipe (`cargo audit`/`pip-audit`/`trivy`).
`postgres:14` ages.

### A07 AuthN/AuthZ — Main vector

Worker has no auth beyond Postgres ACLs: DB write = send
capability. CLI subcommands unauthenticated; `inspect` dumps full
`traceback` + `args_kwargs`. `get_status()` uses
`import_string(PILOTWAVE_STATUS_PROVIDER)` (`client.py`) — RCE if
settings compromised (Django-settings trust, must be documented).
Daemon `flock` + cmdline identity check correct.

### A08 Integrity — Strong on attachments

No row signatures (relies on DB ACLs). `schema:1` strict
kwargs-only. Attachment pipeline
(`attachments.rs::load`): charset → absolute → symlink-ancestors →
canonicalize → deny `/proc,/sys,/dev,/etc` → roots prefix →
real-size caps → `take(MAX+1)`. Fail-closed on broken roots.

### A09 Logging — Good, CLI leak

Heartbeat metadata counters-only (`heartbeat.rs`), `reference`
never in heartbeat, secrets redacted in logs/BD. Leak: `inspect`
/ `log` print raw PII to stdout.

### A10 SSRF — N/A

No URL fetches; bodies/attachments never dereferenced as URLs.
Only configurable egress: `EMAIL_HOST`, `DATABASE_URL`. Compromised
env = exfil to attacker SMTP — protect env files.

## Adversary top 3 (→ debt R-6/R-7/R-8)

1. Planted row + flood → spam/duplicates/SMTP cost.
2. PII read via CLI/BD (`inspect`, traceback).
3. TLS downgrade / DSN in clear (PG no-TLS, `EMAIL_USE_TLS=false`).

Follow-ups tracked as R-6, R-7, R-8 in `04-ROADMAP/README.md`.
